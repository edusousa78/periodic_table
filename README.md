# Periodic Table Database

Projeto freeCodeCamp de banco de dados periódico.

Tecnologias: PostgreSQL, SQL, Bash e Git.

## Usage

./element.sh 1
./element.sh H
./element.sh Hydrogen

The script accepts an atomic number, symbol, or element name.

## Database tables

- elements: atomic number, symbol, and name.
- properties: atomic mass and temperatures.
- types: chemical element classifications.
